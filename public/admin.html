 1. Adding WhatsApp Bots & Linking via Pairing Code (نیا بوٹ ایڈ اور کنیکٹ کرنا)

              
            

            

              

                
How WhatsApp Device Linking Works

                
To connect a WhatsApp account (Personal or Business):

                
    
                  
  1. Click Add WhatsApp Bot.
    2. 
                  
  2. Enter the bot label (e.g. "Primary WhatsApp").
    3. 
                  
  3. The country code +92 is locked. Enter the 10 digits starting with 3 (e.g. 3495031007). Never enter a leading 0!
    4. 
                  
  4. Click Generate Pairing Code. You will receive an 8-character code formatted as XXXX-XXXX.
    5. 
                  
  5. On your phone, open WhatsApp > Settings > Linked Devices > Link with phone number and type the code.
    6. 
                  
  6. The bot connects within seconds and turns green (🟢 Ready).
    7. 
                

              

              

                
واٹس ایپ بوٹ کنیکٹ کرنے کا مکمل طریقہ

                
نیا واٹس ایپ اکاؤنٹ (پرسنل یا بزنس) منسلک کرنے کے لیے:

                
    
                  
  1. Add WhatsApp Bot کے بٹن پر کلک کریں۔
    2. 
                  
  2. بوٹ کا نام درج کریں (مثال: Main WhatsApp)۔
    3. 
                  
  3. کنٹری کوڈ +92 پہلے سے لاک ہے۔ آپ نے نمبر 3 سے شروع کرنا ہے (مثال: 3495031007)۔ شروع میں 0 ہرگز نہ لکھیں!
    4. 
                  
  4. Generate Pairing Code پر کلک کریں۔ 8 ہندسوں کا کوڈ آئے گا جیسے XXXX-XXXX۔
    5. 
                  
  5. اپنے موبائل میں واٹس ایپ کھولیں > سیٹنگز > Linked Devices > Link with phone number میں جا کر یہ کوڈ درج کریں۔
    6. 
                  
  6. بوٹ فوری طور پر ایکٹو ہو جائے گا اور سبز (🟢 Ready) نشان آ جائے گا۔
    7. 
                

              

            

          


          
          

            

              
 2. Direct Chat & Custom Messages (براہِ راست میسجنگ فیچر)

              
            

            

              

                
Direct Messaging Without OTP Logic

                
The Direct Chat tab allows administrators to send custom WhatsApp messages from any linked bot directly to any mobile number:

                
    
                  
  • Select which connected bot account should send the message.
    • 
                  
  • Enter the recipient Pakistani number starting with 3 (locked +92 prefix).
    • 
                  
  • Type custom text with WhatsApp markdown (*bold*, _italic_, ~strike~, ```code```).
    • 
                  
  • The message is sent immediately and tracked with delivery receipt confirmation.
    • 
                

              

              

                
بغیر او ٹی پی کے براہِ راست پیغام بھیجنا

                
Direct Chat ٹیب کے ذریعے آپ کسی بھی جڑے ہوئے بوٹ سے کسی بھی نمبر پر اپنی مرضی کا میسج بھیج سکتے ہیں:

                
    
                  
  • منتخب کریں کہ کس بوٹ کے نمبر سے میسج بھیجنا ہے۔
    • 
                  
  • وصول کنندہ کا پاکستانی نمبر 3 سے شروع کر کے لکھیں۔
    • 
                  
  • میسج ٹائپ کریں اور بولڈ یا اٹیلک فارمیٹنگ استعمال کر سکتے ہیں۔
    • 
                  
  • میسج فوری چلا جائے گا اور ایڈمن پینل میں ڈلیوری کی تصدیق مل جائے گی۔
    • 
                

              

            

          


          
          

            

              
 3. Gateway Settings & Security Parameters (تمام سیٹنگز کی تفصیلی وضاحت)

              
            

            

              

                
Explanation of Each Configuration Field

                
    
                  
  • OTP Lifetime (sec): How long the 6-digit code remains valid before expiring (Default: 300s = 5 mins).
    • 
                  
  • Resend Cooldown (sec): Minimum seconds a user must wait before requesting another OTP (Default: 60s).
    • 
                  
  • Max OTPs / Hour (Global): Maximum total OTPs the gateway will send per hour to prevent account flagging.
    • 
                  
  • Max Per IP / Hour: Rate limit per IP address to block bots and brute-force attacks (Default: 10).
    • 
                  
  • Daily Global OTP Limit: Maximum OTP dispatches allowed across the whole gateway per calendar day.
    • 
                  
  • Warmup Delay (sec): Delay after linking a new bot before it begins processing live OTP queues.
    • 
                  
  • Test Mode (Restrict to Allowed): When checked, OTPs will ONLY be sent to numbers in the whitelist.
    • 
                

              

              

                
سیٹنگز کے تمام آپشنز کی آسان وضاحت

                
    
                  
  • او ٹی پی کی میعاد (OTP Lifetime): وہ وقت جس کے بعد او ٹی پی ضائع ہو جاتا ہے (ڈیفالٹ: 300 سیکنڈ یعنی 5 منٹ)۔
    • 
                  
  • دوبارہ بھیجنے کا وقفہ (Cooldown): ایک بار کوڈ مانگنے کے بعد دوبارہ مانگنے کے درمیان لازمی وقفہ (ڈیفالٹ: 60 سیکنڈ)۔
    • 
                  
  • فی گھنٹہ حد (Max Per Hour): واٹس ایپ اکاؤنٹ کو محفوظ رکھنے کے لیے فی گھنٹہ زیادہ سے زیادہ پیغامات کی حد۔
    • 
                  
  • آئی پی لمٹ (Max Per IP): ایک ہی انٹرنیٹ کنکشن یا موبائل سے بار بار جعلی حملوں کو روکنے کے لیے حد۔
    • 
                  
  • یومیہ حد (Daily Limit): 24 گھنٹوں میں تمام بوٹس سے کل بھیجے جانے والے او ٹی پی کی زیادہ سے زیادہ حد۔
    • 
                  
  • وارم اپ تاخیر (Warmup): نیا بوٹ لنک ہوتے ہی فوراً لوڈ نہ ڈالیں بلکہ کچھ سیکنڈ وارم اپ ہونے دیں۔
    • 
                  
  • ٹیسٹ موڈ (Test Mode): اسے آن کرنے پر صرف ان نمبرز پر او ٹی پی جائے گا جو وائٹ لسٹ میں لکھے ہوں گے۔
    • 
                

              

            

          


          
          

            

              
 4. API Keys & Integration Guide (ویب سائٹ یا ایپ میں جوڑنے کا طریقہ)

              
            

            

              

                
Connecting to External Systems

                
Every website, PHP script, Python backend, or mobile app connects using the x-api-key header:

                
    
                  
  • Endpoint for sending OTP: POST /api/v1/send-otp
    • 
                  
  • Payload: {"number": "923495031007"}
    • 
                  
  • Verification Endpoint: POST /api/v1/verify-otp
    • 
                  
  • Payload: {"number": "923495031007", "otp": "123456"}
    • 
                

              

              

                
اپنی ویب سائٹ یا موبائل ایپ میں جوڑنے کا طریقہ

                
اپنی کسی بھی ویب سائٹ، ایچ ٹی ایم ایل فارم، یا پی ایچ پی کوڈ میں سرور جوڑنے کا طریقہ:

                
    
                  
  • او ٹی پی بھیجنے کی اے پی آئی: POST /api/v1/send-otp
    • 
                  
  • ہیڈر میں اپنی خفیہ کی بھیجیں: x-api-key: YOUR_KEY
    • 
                  
  • تصدیق کرنے کی اے پی آئی: POST /api/v1/verify-otp
    • 
                  
  • نمبر اور صارف کا لکھا ہوا 6 ہندسوں کا کوڈ بھیجیں، سسٹم فوراً تصدیق کر دے گا۔
    •
